# ddpm.com.my: DDP Management website

Static website (HTML, CSS, JavaScript, self-hosted fonts). No server code; Nginx serves `site/`.
English and Bahasa Melayu, switched in the header.

```
site/                 the website (Nginx serves this folder)
  index.html          generated by build/build.py
  assets/site.css     styles and the slide animations
  assets/site.js      slideshow, language switch, dividend estimator, menu, enquiry form
  assets/i18n.js      English and Bahasa Melayu text (generated)
  assets/fonts/       Bricolage Grotesque and Figtree
build/
  build.py            all page text (English, Bahasa Melayu) and layout; run it after editing
  art.py              the animated cartoon scenes and people (SVG)
deploy/
  ddpm.conf           Nginx site configuration with security headers
  update.sh           publish the latest version on the VPS
```

## Changing text

Edit the English and Bahasa Melayu text in `build/build.py` (the `T` list), then run:

```
python build/build.py
```

This rewrites `site/index.html` and `site/assets/i18n.js`. Don't edit those two files by hand; your changes would be lost at the next build.

## Before going live

- Replace `[+60 X-XXX XXXX]` and `[Address]` in `build/build.py`, then rebuild
- Confirm the mailbox `info@ddpm.com.my` (also used in `site/assets/site.js`)
- Replace the placeholder logo (the mark in `build/build.py`, `LOGO_MARK`) with DDPM's real logo if you have one
- Confirm the koperasi case study can be named publicly

## Preview on your PC

From the `site` folder: `npx serve -l 8080`, then open http://localhost:8080.

## Hosting on the VPS

Same pattern as svstechworks.com: Git clone in `/srv/ddpm/site`, Nginx root `/srv/ddpm/site/site`,
`deploy/update.sh` to publish. See the reply for DNS: the domain's email (MX) records must be kept.
